双击「启动乐伴.bat」。
浏览器和桌宠会自动打开。点击网页上的「开始陪伴」后，才会开启摄像头；麦克风需要在浏览器中授权。

点击桌宠可展开面板，查看心情、屏幕前时间和喝水次数，并使用聊天、呼吸、情绪、音乐、主页和开始或结束陪伴。开始陪伴前会确认摄像头采集。拖动桌宠可以移动位置，右键可以打开快捷菜单。关闭桌宠后，可以从网页顶部的「桌宠」重新打开。

网页右上角头像可打开个人资料及常用页面。昵称和头像与乐伴社区的本地资料同步，保存在当前浏览器中。

在「和乐伴聊聊」页面点击「API 设置」可保存或更换 DeepSeek API Key。密钥明文保存在本机配置文件中；若系统环境变量已配置密钥，则优先使用环境变量。保存时不会验证密钥是否有效。

关闭摄像头画面只会隐藏预览，不会停止采集；要停止摄像头，请点击网页上的「结束陪伴」。情绪结果仅供参考，不是医疗判断。
记录和相册保存在本机。使用 DeepSeek 聊天或相册 AI 文案时，相关记录或照片会发送给外部服务。
关掉弹出的黑色窗口，乐伴和桌宠就会退出。
